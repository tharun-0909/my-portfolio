# Tharun Gandla — Portfolio

A responsive, navy-blue personal portfolio built with React and Vite. It presents my full-stack development work, MERN projects, experience, education, skills, and contact links.

## Features

- Responsive layout for desktop and mobile
- Dark navy theme with custom CSS styling
- Project cards linking to live demos and GitHub repositories
- About, skills, experience, education, and contact sections
- Downloadable résumé

## Tech stack

- React
- Vite
- JavaScript
- CSS

## Run locally

### Prerequisites

- Node.js 18 or later
- npm

### Install and start

From the project directory, install dependencies and start the Vite development server:

```powershell
npm.cmd install
npm.cmd run dev
```

## Production build

Build the site for deployment:

```powershell
npm.cmd run build
```

Vite writes the generated static site to `dist/`. To preview the production build locally:

```powershell
npm.cmd run preview
```

Deploy the contents of `dist/` to a static hosting service such as Vercel or Netlify.
